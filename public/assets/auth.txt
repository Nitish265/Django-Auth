Awesome project idea. Let’s build a clean Django + DRF API that uses:
- MySQL for Django’s internal tables (sessions, migrations, admin)
- MongoDB for all your app data (users, tokens, otps, deleted users)
- Secure OTPs with strict rules (cooldowns, expiration, uniqueness)
- Token-based auth that supports “logout from all devices,” auto-logout after 10 days of inactivity, and lockouts after wrong passwords
- Soft delete + restore + admin blacklisting

I’ll walk you through every step like you asked, with code that’s heavily commented so even a beginner can follow along.

----------------------------------------
What we’re building (features)
----------------------------------------
- Signup with unique username/email/phone + role + full name + password + confirm password
- Send OTP to verify signup
  - OTP expires after 10 minutes (auto delete via MongoDB TTL)
  - Resend OTP allowed after 2 minutes (old OTP deleted)
  - OTP is tied to the user; can’t be used by others
  - If user stays unverified for 10 minutes, delete the user automatically (via MongoDB TTL)
- Login/Logout with tokens stored in MongoDB
  - After 10 wrong password attempts -> lock login for 10 minutes
  - Logout from current device or all devices
  - Auto-logout after 10 days of inactivity (no API calls) via MongoDB TTL
- Forgot password via OTP
  - OTP is separate from signup OTP and can’t be reused
  - When password is reset, logout from all devices
- Delete account (soft delete to a deleted_users collection)
  - Admin can restore users from deleted
- Blacklist/unblacklist users (admin-only)
  - Blacklisted users cannot log in or use existing tokens

We’ll rely on MongoDB TTL indexes to auto-delete OTPs, unverified users, and auto-logout inactive tokens.

----------------------------------------
Tech stack and why
----------------------------------------
- Django + DRF: easy API building and validation
- PyMongo: talk to MongoDB directly (no ORM complications)
- MySQL: default Django tables (no app data there)
- MongoDB TTL indexes: automatic time-based deletions
- Custom Token Auth: simple tokens stored in Mongo, easy to revoke/expire

```python
# core/accounts/indexes.py
from datetime import timedelta
from pymongo import ASCENDING
from django.conf import settings
from .mongo import users_col, otps_col, tokens_col, deleted_users_col

def ensure_mongo_indexes():
    # USERS
    # Unique constraints so duplicates can't be inserted
    users_col.create_index([("username", ASCENDING)], unique=True, name="uniq_username")
    users_col.create_index([("email", ASCENDING)], unique=True, name="uniq_email")
    users_col.create_index([("phone", ASCENDING)], unique=True, name="uniq_phone")

    # TTL to delete UNVERIFIED users after 10 minutes:
    # We set a field "delete_at" only for unverified users; when verified, we unset it.
    # expireAfterSeconds=0 means delete exactly at the time in delete_at.
    users_col.create_index([("delete_at", ASCENDING)], expireAfterSeconds=0, name="ttl_unverified_delete")

    # OTPS
    # Ensure one OTP per user per type (signup or password_reset)
    otps_col.create_index([("user_id", ASCENDING), ("otp_type", ASCENDING)], unique=True, name="uniq_user_type")
    # Auto-delete OTPs after OTP_TTL_SECONDS (e.g., 600 seconds = 10 minutes)
    otps_col.create_index([("created_at", ASCENDING)], expireAfterSeconds=settings.OTP_TTL_SECONDS, name="ttl_otp")

    # TOKENS
    # Token strings must be unique
    tokens_col.create_index([("token", ASCENDING)], unique=True, name="uniq_token")
    # Auto-delete tokens after X seconds of no activity (we update last_activity on every request)
    tokens_col.create_index([("last_activity", ASCENDING)], expireAfterSeconds=settings.TOKEN_INACTIVITY_TTL_SECONDS, name="ttl_token_inactivity")

    # DELETED_USERS: no special index required, but you could add on username/email/phone for admin lookups
```

Why TTL is magic:
- You don’t need a cron job to delete OTPs/tokens/unverified users. Mongo does it for you!

```python
# core/accounts/utils/security.py
import secrets
import hmac
import hashlib
from django.contrib.auth.hashers import make_password, check_password
from django.conf import settings

def hash_password(raw_password: str) -> str:
    # Uses Django's secure password hashing (PBKDF2 by default)
    return make_password(raw_password)

def verify_password(raw_password: str, hashed_password: str) -> bool:
    return check_password(raw_password, hashed_password)

def generate_token() -> str:
    # A random, URL-safe token string. Treat it like a password.
    return secrets.token_urlsafe(32)

def hash_otp(code: str) -> str:
    # We hash OTP with HMAC-SHA256 so even if DB is leaked, OTPs aren't readable
    secret = settings.SECRET_KEY.encode("utf-8")
    return hmac.new(secret, code.encode("utf-8"), hashlib.sha256).hexdigest()

def constant_time_compare(a: str, b: str) -> bool:
    # Compare in constant time to avoid timing attacks
    return hmac.compare_digest(a, b)
```

```python
# core/accounts/repositories.py
from datetime import datetime, timedelta
from typing import Optional, Dict, Any
from bson import ObjectId
from pymongo.errors import DuplicateKeyError
from django.conf import settings
from .mongo import users_col, otps_col, tokens_col, deleted_users_col
from .utils.security import hash_password, verify_password, hash_otp
from .utils.security import generate_token as generate_session_token

def now_utc():
    return datetime.utcnow()

def to_object_id(_id: str) -> ObjectId:
    return ObjectId(_id)

# ---------- Users ----------
def create_user(user_data: Dict[str, Any]) -> Dict[str, Any]:
    """
    Inserts a new user into Mongo 'users' collection.
    user_data must include: username, email, phone, full_name, role, password (raw)
    """
    doc = {
        "username": user_data["username"].strip(),
        "email": user_data["email"].strip().lower(),
        "phone": user_data["phone"].strip(),
        "full_name": user_data["full_name"].strip(),
        "role": user_data.get("role", "user"),
        "password_hash": hash_password(user_data["password"]),
        "is_verified": False,
        "is_blacklisted": False,
        "failed_login_count": 0,
        "lock_until": None,
        "created_at": now_utc(),
        "updated_at": now_utc(),
        # For unverified users, set a delete_at in 10 minutes: Mongo TTL will delete them if they never verify.
        "delete_at": now_utc() + timedelta(seconds=settings.OTP_TTL_SECONDS),
    }
    try:
        result = users_col.insert_one(doc)
        doc["_id"] = result.inserted_id
        return doc
    except DuplicateKeyError as e:
        # Unique index violation (username/email/phone)
        raise ValueError("Username, email, or phone already exists") from e

def find_user_by_identifier(identifier: str) -> Optional[Dict[str, Any]]:
    """
    Allows login/lookup by username OR email OR phone.
    Very simple detection: if contains '@' => email, if digits => phone, else => username.
    """
    ident = identifier.strip()
    query = None
    if "@" in ident:
        query = {"email": ident.lower()}
    elif ident.isdigit():
        query = {"phone": ident}
    else:
        query = {"username": ident}
    return users_col.find_one(query)

def find_user_by_id(user_id: ObjectId) -> Optional[Dict[str, Any]]:
    return users_col.find_one({"_id": user_id})

def mark_user_verified(user_id: ObjectId):
    # Verified users should not be auto-deleted, so unset delete_at
    users_col.update_one({"_id": user_id}, {"$set": {"is_verified": True, "updated_at": now_utc()},
                                            "$unset": {"delete_at": ""}})

def set_user_lock(user_id: ObjectId, minutes: int):
    users_col.update_one({"_id": user_id}, {"$set": {"lock_until": now_utc() + timedelta(minutes=minutes), "failed_login_count": 0}})

def reset_failed_logins(user_id: ObjectId):
    users_col.update_one({"_id": user_id}, {"$set": {"failed_login_count": 0}})

def increment_failed_logins(user_id: ObjectId) -> int:
    # Atomically increment and return the new count
    updated = users_col.find_one_and_update(
        {"_id": user_id},
        {"$inc": {"failed_login_count": 1}},
        return_document=True
    )
    return updated["failed_login_count"]

def update_password(user_id: ObjectId, new_password: str):
    users_col.update_one({"_id": user_id}, {"$set": {"password_hash": hash_password(new_password), "updated_at": now_utc()}})

def is_user_blacklisted(user_doc: Dict[str, Any]) -> bool:
    return user_doc.get("is_blacklisted", False)

def set_blacklist(user_id: ObjectId, value: bool):
    users_col.update_one({"_id": user_id}, {"$set": {"is_blacklisted": value, "updated_at": now_utc()}})

def refresh_unverified_delete_timer(user_id: ObjectId):
    # When resending signup OTP, give them another 10 minutes or OTP_TTL_SECONDS
    users_col.update_one({"_id": user_id}, {"$set": {"delete_at": now_utc() + timedelta(seconds=settings.OTP_TTL_SECONDS)}})

def move_user_to_deleted(user_doc: Dict[str, Any]):
    # Insert into deleted_users then remove from users; also add deleted_at timestamp
    doc = dict(user_doc)
    doc["deleted_at"] = now_utc()
    deleted_users_col.insert_one(doc)
    users_col.delete_one({"_id": user_doc["_id"]})

def restore_deleted_user_by_identifier(identifier: str) -> Dict[str, Any]:
    # Try to find in deleted_users by username/email/phone and move back to users.
    ident = identifier.strip()
    if "@" in ident:
        query = {"email": ident.lower()}
    elif ident.isdigit():
        query = {"phone": ident}
    else:
        query = {"username": ident}

    doc = deleted_users_col.find_one(query)
    if not doc:
        raise ValueError("Deleted user not found")

    # Remove fields that should not conflict or re-create
    doc.pop("_id")        # new _id will be created
    doc.pop("deleted_at", None)

    # Try to insert back; if unique conflicts exist, it will fail
    from pymongo.errors import DuplicateKeyError
    try:
        users_col.insert_one(doc)
    except DuplicateKeyError:
        raise ValueError("Cannot restore: username/email/phone already taken by another user")

    # Remove from deleted_users
    deleted_users_col.delete_one(query)
    return doc

# ---------- OTPs ----------
def get_user_otp(user_id: ObjectId, otp_type: str) -> Optional[Dict[str, Any]]:
    return otps_col.find_one({"user_id": user_id, "otp_type": otp_type})

def delete_user_otp(user_id: ObjectId, otp_type: str):
    otps_col.delete_one({"user_id": user_id, "otp_type": otp_type})

def create_or_replace_otp(user_id: ObjectId, otp_type: str, code_plain: str, sent_via: str) -> Dict[str, Any]:
    # Ensure only one OTP exists per user per type: delete old and insert new
    delete_user_otp(user_id, otp_type)
    doc = {
        "user_id": user_id,
        "otp_type": otp_type,  # "signup" or "password_reset"
        "code_hash": hash_otp(code_plain),
        "created_at": now_utc(),
        "sent_via": sent_via,
    }
    otps_col.insert_one(doc)
    return doc

# ---------- Tokens ----------
def create_token(user_id: ObjectId, ip: str, user_agent: str) -> Dict[str, Any]:
    token_str = generate_session_token()
    doc = {
        "user_id": user_id,
        "token": token_str,
        "ip": ip,
        "user_agent": user_agent,
        "issued_at": now_utc(),
        "last_activity": now_utc(),  # TTL refreshes when this timestamp updates
        "revoked": False,            # Not used here; we delete tokens instead of setting revoked
    }
    tokens_col.insert_one(doc)
    return doc

def update_token_last_activity(token_str: str):
    tokens_col.update_one({"token": token_str}, {"$set": {"last_activity": now_utc()}})

def find_token(token_str: str) -> Optional[Dict[str, Any]]:
    return tokens_col.find_one({"token": token_str})

def delete_token(token_str: str):
    tokens_col.delete_one({"token": token_str})

def delete_all_tokens_for_user(user_id: ObjectId):
    tokens_col.delete_many({"user_id": user_id})
```

Step 11: Authentication class (accounts/authentication.py)
----------------------------------------
This reads the token from Authorization header, looks it up in Mongo, checks the user, and updates last_activity so TTL won’t delete active tokens.

```python
# core/accounts/authentication.py
from typing import Optional, Tuple
from rest_framework.authentication import BaseAuthentication, get_authorization_header
from rest_framework.exceptions import AuthenticationFailed
from django.utils.translation import gettext_lazy as _
from .repositories import find_token, find_user_by_id, update_token_last_activity, is_user_blacklisted
from bson import ObjectId

class MongoUser:
    """
    A tiny user wrapper so DRF sees request.user as authenticated.
    """
    def __init__(self, user_doc):
        self.id = str(user_doc["_id"])
        self.username = user_doc["username"]
        self.email = user_doc["email"]
        self.phone = user_doc["phone"]
        self.role = user_doc.get("role", "user")
        self.is_verified = user_doc.get("is_verified", False)
        self.is_blacklisted = user_doc.get("is_blacklisted", False)

    @property
    def is_authenticated(self):
        return True

    def is_admin(self):
        return self.role == "admin"

class MongoTokenAuthentication(BaseAuthentication):
    keyword = "Bearer"

    def authenticate(self, request) -> Optional[Tuple[MongoUser, str]]:
        auth = get_authorization_header(request).split()

        if not auth or auth[0].lower() != self.keyword.lower().encode():
            return None  # No auth header; DRF will treat as anonymous, unless view requires auth

        if len(auth) == 1:
            raise AuthenticationFailed(_("Invalid token header. No credentials provided."))
        elif len(auth) > 2:
            raise AuthenticationFailed(_("Invalid token header. Token string should not contain spaces."))

        token_str = auth[1].decode()
        token_doc = find_token(token_str)
        if not token_doc:
            raise AuthenticationFailed(_("Invalid or expired token"))

        user_doc = find_user_by_id(token_doc["user_id"])
        if not user_doc:
            raise AuthenticationFailed(_("User not found"))

        if not user_doc.get("is_verified", False):
            raise AuthenticationFailed(_("User not verified"))

        if is_user_blacklisted(user_doc):
            raise AuthenticationFailed(_("User is blacklisted"))

        # Update last_activity to keep token alive
        update_token_last_activity(token_str)

        return (MongoUser(user_doc), token_str)
```

class SignupView(APIView):
    permission_classes = [permissions.AllowAny]

    def post(self, request):

        Create a new user (unverified), send signup OTP, and set auto-delete in 10 minutes.
        """

            return Response({"errors": ser.errors}, status=status.HTTP_400_BAD_REQUEST)

        try:
            user_doc = create_user(data)
        except ValueError as e:
            return Response({"message": str(e)}, status=status.HTTP_409_CONFLICT)

        # Generate OTP and send (by email OR sms; here we’ll prefer email if available)

        else:
            send_sms(user_doc["phone"], f"Your OTP is: {otp_code}")

        return Response({
            "message": "Signup successful. OTP sent. Verify within 10 minutes.",
            "note": "If you don't verify within 10 minutes, your account will be deleted automatically."

class ResendSignupOtpView(APIView):
    permission_classes = [permissions.AllowAny]

    def post(self, request):
        """
        Resend signup OTP after a 2-minute cooldown. Old OTP is deleted.
        Also refreshes the user's unverified delete timer.
        """
        ser = IdentifierSerializer(data=request.data)
        if not ser.is_valid():
            return Response({"errors": ser.errors}, status=status.HTTP_400_BAD_REQUEST)

        user_doc = find_user_by_identifier(ser.validated_data["identifier"])
        if not user_doc:
            return Response({"message": "User not found"}, status=status.HTTP_404_NOT_FOUND)

        if user_doc.get("is_verified", False):
            return Response({"message": "User already verified"}, status=status.HTTP_400_BAD_REQUEST)

        # Check cooldown (2 minutes since last OTP)
        otp_doc = get_user_otp(user_doc["_id"], "signup")
        if otp_doc:
            age_seconds = (datetime.utcnow() - otp_doc["created_at"]).total_seconds()
            if age_seconds < settings.OTP_COOLDOWN_SECONDS:
                wait = int(settings.OTP_COOLDOWN_SECONDS - age_seconds)
                return Response({"message": f"Please wait {wait} more seconds before requesting a new OTP."},
                                status=status.HTTP_429_TOO_MANY_REQUESTS)

        # Create new OTP (delete old automatically in repo), refresh delete timer
        otp_code = generate_otp()
        create_or_replace_otp(user_doc["_id"], "signup", otp_code, "email" if user_doc.get("email") else "sms")
        refresh_unverified_delete_timer(user_doc["_id"])

        if user_doc.get("email"):
            send_email(user_doc["email"], "Your Signup OTP", f"Your OTP is: {otp_code}")
        else:
            send_sms(user_doc["phone"], f"Your OTP is: {otp_code}")

        return Response({"message": "New OTP sent. Verify within 10 minutes."})

class VerifySignupOtpView(APIView):
    permission_classes = [permissions.AllowAny]

    def post(self, request):
        """
        Verify the signup OTP. If correct, mark user as verified and delete the OTP instantly.
        """
        ser = VerifyOtpSerializer(data=request.data)
        if not ser.is_valid():
            return Response({"errors": ser.errors}, status=status.HTTP_400_BAD_REQUEST)

        user_doc = find_user_by_identifier(ser.validated_data["identifier"])
        if not user_doc:
            return Response({"message": "User not found"}, status=status.HTTP_404_NOT_FOUND)

        if user_doc.get("is_verified", False):
            return Response({"message": "User already verified"}, status=status.HTTP_400_BAD_REQUEST)

        otp_doc = get_user_otp(user_doc["_id"], "signup")
        if not otp_doc:
            # Could be expired (auto-deleted after 10 min)
            return Response({"message": "OTP not found or expired"}, status=status.HTTP_400_BAD_REQUEST)

        # Check OTP
        from .utils.security import hash_otp
        provided_hash = hash_otp(ser.validated_data["otp"])
        if not constant_time_compare(provided_hash, otp_doc["code_hash"]):
            return Response({"message": "Invalid OTP"}, status=status.HTTP_400_BAD_REQUEST)

        # Success: mark verified, delete OTP immediately
        mark_user_verified(user_doc["_id"])
        delete_user_otp(user_doc["_id"], "signup")

        return Response({"message": "Signup verified. You can now log in."})

class LoginView(APIView):
    permission_classes = [permissions.AllowAny]

    def post(self, request):
        """
        Log in with username/email/phone and password.
        - Must be verified and not blacklisted
        - Locks after too many failed attempts
        - Returns a token used in Authorization: Bearer <token>
        """
        ser = LoginSerializer(data=request.data)
        if not ser.is_valid():
            return Response({"errors": ser.errors}, status=status.HTTP_400_BAD_REQUEST)

        user_doc = find_user_by_identifier(ser.validated_data["identifier"])
        if not user_doc:
            return Response({"message": "Invalid credentials"}, status=status.HTTP_400_BAD_REQUEST)

        # Must be verified
        if not user_doc.get("is_verified", False):
            return Response({"message": "User is not verified"}, status=status.HTTP_403_FORBIDDEN)

        # Lockout check
        lock_until = user_doc.get("lock_until")
        if lock_until and lock_until > datetime.utcnow():
            delta = int((lock_until - datetime.utcnow()).total_seconds())
            return Response({"message": f"Account locked. Try again in {delta} seconds."}, status=status.HTTP_403_FORBIDDEN)

        # Check password
        from .utils.security import verify_password
        if not verify_password(ser.validated_data["password"], user_doc["password_hash"]):
            new_count = increment_failed_logins(user_doc["_id"])
            if new_count >= settings.MAX_FAILED_LOGINS:
                set_user_lock(user_doc["_id"], settings.LOGIN_LOCK_MINUTES)
                return Response({"message": "Too many wrong attempts. Account locked for 10 minutes."}, status=status.HTTP_403_FORBIDDEN)
            return Response({"message": "Invalid credentials"}, status=status.HTTP_400_BAD_REQUEST)

        # Success: reset failed count, issue token
        reset_failed_logins(user_doc["_id"])
        tok = create_token(user_doc["_id"], client_ip(request), user_agent(request))
        return Response({
            "message": "Login successful",
            "token": tok["token"],
            "inactivity_logout_seconds": settings.TOKEN_INACTIVITY_TTL_SECONDS
        })

----------------------------------------
How it all works together (plain English)
----------------------------------------
- When someone signs up:
  - We create a user in Mongo with is_verified = false and set delete_at = now + 10 minutes.
  - We create an OTP record tied to that user and send it by email or SMS.
  - Mongo DB will automatically delete the user after 10 minutes if they never verify (TTL on users.delete_at).
  - The OTP also auto-deletes after 10 minutes (TTL on otps.created_at).
  - If they ask for a new OTP, we check they waited 2 minutes before sending a fresh one. We delete the old OTP and refresh delete_at to give them another 10 minutes.
  - When they verify OTP, we mark them verified and remove delete_at, so Mongo won’t delete them.

- Login:
  - Only verified, not-blacklisted users can log in.
  - If they fail 10 times, we lock them for 10 minutes.
  - If they succeed, we create a token stored in Mongo with last_activity=now.
  - On every authenticated request, our auth class updates last_activity (keeps them logged in).
  - Mongo automatically deletes (logs out) tokens with no activity for 10 days (TTL on tokens.last_activity).

- Logout:
  - Delete current token (logout only this device)
  - Or delete all tokens (logout from all devices)

- Forgot password:
  - Verified user requests OTP (cooldown 2 minutes, expires 10 minutes).
  - They verify OTP and provide a new password in the same call.
  - If correct, we delete the OTP, set the new password, and force logout from all devices by deleting tokens.

- Delete account:
  - Move user doc from users to deleted_users (so we can restore if needed).
  - Delete all tokens.

- Admin:
  - Can restore a deleted user (unless someone else took their username/email/phone).
  - Can blacklist/unblacklist users. Blacklisting logs them out immediately and blocks login.

Security and production notes
----------------------------------------
- Always use HTTPS in production so tokens/OTPs aren’t sniffed
- Replace send_email/send_sms with real providers and DO NOT log OTPs
- Keep SECRET_KEY secret
- Consider rate-limiting endpoints (e.g., django-ratelimit) to stop abuse
- Validate phone numbers (e.g., with python-phonenumbers) if you rely on SMS
- Backups: TTL deletes docs automatically; ensure that’s your intended behavior

    - What: Custom DRF auth class (MongoTokenAuthentication).
    - How it works:
      - Reads Authorization: Bearer <token>
      - Looks up the token in Mongo (tokens collection)
      - Finds the user in Mongo (users collection)
      - Checks verified and not blacklisted
      - Updates last_activity so token doesn’t auto-expire
      - Attaches request.user and request.auth for the view
  - repositories.py
    - What: The only place that talks to MongoDB directly (CRUD).
    - Why: Keeps views simple and all DB logic in one spot.
    - Sections inside:
      - Users:
        - create_user: makes a new unverified user with delete_at (so Mongo auto-deletes in 10 min if not verified).
        - find_user_by_identifier: login by username/email/phone.
        - mark_user_verified: sets is_verified + removes delete_at (so user won’t be auto-deleted).
        - increment_failed_logins / set_user_lock / reset_failed_logins: login attempts + lockout.
        - update_password: change password (hashes it).
        - set_blacklist: admin blacklist/unblacklist.
        - move_user_to_deleted / restore_deleted_user_by_identifier: soft delete and restore.
        - refresh_unverified_delete_timer: extend the 10 min window on resend OTP.
      - OTPs:
        - get_user_otp, create_or_replace_otp, delete_user_otp.
        - OTPs are hashed (not stored in plain text) and auto-deleted by TTL in Mongo.
      - Tokens:
        - create_token, update_token_last_activity, find_token, delete_token, delete_all_tokens_for_user.
        - Tokens auto-delete (auto-logout) after X days of inactivity via Mongo TTL.
  - mongo.py
    - What: Creates a single MongoDB client and exposes collection handles.
    - Collections used:
      - users_col (users)
      - otps_col (otps)
      - tokens_col (tokens)
      - deleted_users_col (deleted_users)
  - indexes.py
    - What: Creates indexes in MongoDB:
      - Unique indexes on users: username, email, phone.
      - TTL index on users.delete_at to auto-delete unverified users after 10 min.
      - Unique index on (user_id, otp_type) so 1 OTP per user per type.
      - TTL index on otps.created_at so OTPs vanish after 10 min.
      - TTL index on tokens.last_activity for auto-logout after inactivity (e.g., 10 days).
    - Called automatically by apps.py at startup.
  - utils/
    - security.py
      - hash_password / verify_password: uses Django’s secure hashing.
      - generate_token: creates random login tokens.
      - hash_otp + constant_time_compare: store/compare OTPs securely.
    - otp.py
      - generate_otp: makes a numeric OTP like “123456”.
    - senders.py
      - send_email / send_sms: placeholders (print). Replace with real providers (SendGrid/Twilio) later.

How everything works together (quick flow)
- Server start
  - Django loads settings.py.
  - accounts/apps.py runs -> ensure_mongo_indexes() creates all unique/TTL indexes.
- When you hit an endpoint
  - core/urls.py -> accounts/urls.py -> a view in views.py.
  - If endpoint needs auth: authentication.py checks the token and user, refreshes last_activity.
  - View uses serializers.py to validate input.
  - View calls repositories.py to read/write Mongo.
  - Utils handle hashing, OTP generation, sending messages.
  - Response goes back to the client.

Where to change behavior (common tweaks)
- OTP length/time: settings.py (OTP_LENGTH, OTP_TTL_SECONDS).
- OTP resend cooldown: settings.py (OTP_COOLDOWN_SECONDS).
- Auto-logout inactivity window: settings.py (TOKEN_INACTIVITY_TTL_SECONDS).
- Login lockout rules: settings.py (MAX_FAILED_LOGINS, LOGIN_LOCK_MINUTES).
- Email/SMS provider: replace utils/senders.py with your real integrations.
- Unique fields: indexes.py (username/email/phone uniqueness), plus create_user fields.

Endpoints quick map (URL -> view -> what it does)
- POST /api/auth/signup -> SignupView -> create unverified user + send signup OTP.
- POST /api/auth/signup/resend-otp -> ResendSignupOtpView -> new OTP after 2 min; old OTP deleted.
- POST /api/auth/signup/verify-otp -> VerifySignupOtpView -> verify OTP; user becomes verified.
- POST /api/auth/login -> LoginView -> returns Bearer token; handles lockouts.
- POST /api/auth/logout -> LogoutView -> deletes current token.
- POST /api/auth/logout-all -> LogoutAllView -> deletes all tokens for user.
- POST /api/auth/forgot-password/request-otp -> ForgotPasswordRequestOtpView -> sends password reset OTP.
- POST /api/auth/forgot-password/verify-and-reset -> VerifyOtpAndResetPasswordView -> verifies OTP, sets new password, logs out everywhere.
- DELETE /api/user -> DeleteAccountView -> soft deletes user (moves to deleted_users).
- POST /api/admin/users/blacklist -> AdminBlacklistUserView -> blacklist + force logout (admin only).
- POST /api/admin/users/unblacklist -> AdminUnblacklistUserView -> remove blacklist (admin only).
- POST /api/admin/users/restore -> AdminRestoreUserView -> restore from deleted_users (admin only).
- GET /api/me -> MeView -> returns your profile (needs Bearer token).
